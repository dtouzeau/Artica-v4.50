<OCS_AGENT_INTRO>Quando l'OCS Inventory NG Agent viene avviato, interroga il Communication server usando il protocollo HTTP.[br]
Il server pu&#242; non rispondere nulla (non &#232; ora di un inventario e nessun pacchetto da distribuire), e l'agent si ferma.[br]
Altrimenti, il server pu&#242; rispondere che l'Agent deve:
[ul]
[li]Inviare un inventario: l'agent recupera tutte le propriet&#224; del computer e le invia usando il protocollo HTTP al server.[br]
 Il server risponde cos&#236; solo se l'ultima data di inventario nel database &#232; pi&#249; vecchia dell'opzione generale FREQUENCY, specificata in giorni (vedi Gestione delle opzioni generali di OCS Inventory NG).[/li]
[li]Scoprire la rete: l'Agent recupera tutte le propriet&#224; del computer, scansiona la sua sottorete per dispositivi attivi in ascolto sulla rete, poi invia queste informazioni usando il protocollo HTTP al server.[br]
 Il server risponde solo se il computer &#232; eletto per eseguire IPDISCOVERY (vedi Uso della funzionalit&#224; di IP discovery).[/li]
[li]Distribuire un pacchetto: l'Agent contatta il server di distribuzione usando il protocollo HTTPS per ottenere il file di informazioni, scarica i frammenti del pacchetto dal repository, ricostruisce il pacchetto e lo avvia.[/li]
[/ul]</OCS_AGENT_INTRO>
