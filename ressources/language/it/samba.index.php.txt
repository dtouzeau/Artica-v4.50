<domain master>Master di dominio</domain master>
<domain master_text>Abilita il motore di condivisione file per eseguire la raccolta delle liste di esplorazione a livello WAN.[br]
Quando questa opzione è abilitata, il server rivendica un nome NetBIOS speciale specifico del gruppo di lavoro che lo designa come Domain Master Browser per quel gruppo.[br]
I master browser locali situati su sottoreti isolate dal broadcast nello stesso gruppo di lavoro inoltreranno le loro liste locali a questo server. In cambio, richiederanno una lista consolidata che rappresenta lâ%80%99intera rete WAN.[br]
I sistemi client continueranno a contattare il proprio master browser locale, ma riceveranno una lista a livello di dominio invece di una limitata alla sottorete.[br]
[b]Considerazioni importanti:[/b][br]
I Primary Domain Controller (PDC) Windows NT tentano automaticamente di rivendicare il nome NetBIOS speciale che li identifica come Domain Master Browser per il gruppo di lavoro. Questo comportamento non pu%C3² essere disabilitato.[br]
Se questo server rivendica il ruolo di Domain Master Browser prima di un PDC Windows NT, la navigazione tra sottoreti potrebbe comportarsi in modo imprevedibile o non funzionare.[br]
Riepilogo comportamento:[br]

Se abilitato, il server attiva per impostazione predefinita il parametro domain master.[br]

Se domain logons non è abilitato (impostazione predefinita), il ruolo di domain master non sarà attivato automaticamente.[br]

Quando attivo, il motore di condivisione file opera come Primary Domain Controller (PDC).[br]

Quando inattivo, opera come Backup Domain Controller (BDC).[br]
In generale, questo parametro dovrebbe essere disabilitato solo su un BDC.</domain master_text>
