<roundrobin_text>Il DNS Round Robin è una tecnica di distribuzione del carico, bilanciamento o tolleranza ai guasti che fornisce più host di servizi di posta ridondanti,[br]
gestendo le risposte del sistema DNS alle richieste di indirizzo dei server di posta secondo un modello statistico appropriato.[br]
Nella sua implementazione più semplice, il DNS Round Robin risponde alle richieste DNS non con un singolo indirizzo IP,[br]
ma con un elenco di indirizzi IP di più server che ospitano servizi identici.[br]
Lâ%80%99ordine in cui gli indirizzi IP vengono restituiti costituisce il principio del round robin.[br]
Ad ogni risposta DNS, la sequenza degli indirizzi IP viene ruotata.[br]
In genere, i client IP tentano la connessione al primo indirizzo restituito dalla query DNS, consentendo cos%C3%AC la distribuzione del carico tra server diversi.</roundrobin_text>
