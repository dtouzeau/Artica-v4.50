[ul]
[li]Ein Inventar senden: Der Agent ruft alle Computereigenschaften ab und sendet sie &#252;ber das HTTP-Protokoll an den Server.[br]
 Der Server antwortet dies nur, wenn das letzte Inventardatum in der Datenbank &#228;lter ist als die allgemeine Option FREQUENCY, in Tagen angegeben (siehe Verwaltung der allgemeinen OCS-Inventory-NG-Optionen).[/li]
[li]Das Netzwerk erkunden: Der Agent ruft alle Computereigenschaften ab, scannt sein Subnetz nach aktiven Ger&#228;ten, die im Netzwerk lauschen, und sendet diese Informationen dann &#252;ber das HTTP-Protokoll an den Server.[br]
 Der Server antwortet nur, wenn der Computer f&#252;r die Ausf&#252;hrung von IPDISCOVERY ausgew&#228;hlt ist (siehe Verwendung der IP-Discovery-Funktion).[/li]
[li]Ein Paket bereitstellen: Der Agent kontaktiert den Deployment-Server &#252;ber das HTTPS-Protokoll, um die Informationsdatei zu erhalten, l&#228;dt Paketfragmente aus dem Repository herunter, baut das Paket neu auf und startet es.[/li]
[/ul]</OCS_AGENT_INTRO>
