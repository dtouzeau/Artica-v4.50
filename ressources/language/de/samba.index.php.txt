<domain master>Dom&#228;nenmaster</domain master>
<domain master_text>Aktivieren Sie die Dateifreigabe-Engine, um eine WAN-weite Zusammenf%C3%BChrung der Browserlisten durchzuf%C3%BChren.[br]
Wenn diese Option aktiviert ist, beansprucht der Server einen speziellen, arbeitsgruppenspezifischen NetBIOS-Namen, der ihn als Domain Master Browser f%C3%BCr diese Arbeitsgruppe kennzeichnet.[br]
Lokale Master-Browser in broadcast-isolierten Subnetzen derselben Arbeitsgruppe senden ihre lokalen Browserlisten an diesen Server. Im Gegenzug fordern sie eine konsolidierte Liste an, die das gesamte WAN umfasst.[br]
Client-Systeme kontaktieren weiterhin ihren lokalen Master-Browser, erhalten jedoch eine dom%C3%A4nenweite Browserliste anstelle einer auf ihr Subnetz beschr%C3%A4nkten Liste.[br]
[b]Wichtige Hinweise:[/b][br]
Windows NT Primary Domain Controller (PDC) versuchen automatisch, den speziellen NetBIOS-Namen zu beanspruchen, der sie als Domain Master Browser f%C3%BCr ihre Arbeitsgruppe identifiziert. Dieses Verhalten kann nicht deaktiviert werden.[br]
Wenn dieser Server die Rolle des Domain Master Browser %C3%BCbernimmt, bevor ein Windows NT PDC dies tut, kann das subnetz%C3%BCbergreifende Browsing unvorhersehbar reagieren oder fehlschlagen.[br]
Verhaltens%C3%BCbersicht:[br]

Wenn aktiviert, setzt der Server standardm%C3%A4%C3%9Fig den Parameter domain master.[br]

Wenn domain logons nicht aktiviert ist (Standardeinstellung), wird die Domain-Master-Rolle nicht automatisch aktiviert.[br]

Im aktiven Zustand arbeitet die Dateifreigabe-Engine als Primary Domain Controller (PDC).[br]

Im inaktiven Zustand arbeitet sie als Backup Domain Controller (BDC).[br]
Im Allgemeinen sollte dieser Parameter nur auf einem BDC deaktiviert werden.</domain master_text>
